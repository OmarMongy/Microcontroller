# External Protocol References

Place the official ARM AMBA APB specification PDF downloaded by the human in this directory.

Suggested filename: `ARM_AMBA_APB_Specification.pdf` (or retain the exact official filename).

Record in the project task report:
- exact document title and revision/version;
- publication date, if shown;
- source URL;
- local filename;
- which APB protocol version/features are applicable (the project selects APB3).

The PDF is intentionally not bundled in the starter ZIP. Add your downloaded copy locally after extracting the project. Agents must read the supplied document before finalizing APB protocol timing and signal rules. Do not copy the document into public/generated deliverables unless its license permits redistribution.
